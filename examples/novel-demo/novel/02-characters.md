# 人物设定 ·《废土读档指南》

## 1. 主角：江舟
| 维度 | 设定 |
|------|------|
| 年龄/身份 | 25 岁，灾变前外卖骑手，连续三年站点"零投诉"（靠认路、嘴甜、会认怂） |
| 外在目标 | 活下去 → 护苏晚周全、随车队抵达北塬 |
| 内在缺陷 | 怕死到精明，习惯用"试错"代替"承诺"；重生后变本加厉——连感情都像在通关一个会重置的剧情，越来越难对当下、对她认真 |
| 核心能力 | 无限重生：死亡回溯到锚点，记忆完整、物资回档；骑手基本功——活地图、过目不忘的路线、平衡感 |
| 能力代价 | 痛感与死亡体验全额保留；**全世界连同苏晚一起回档、无人记得，几百次相爱的记忆只有他一个人签收**；锚点随成长前移，退路不断消失 |
| 性格 | 嘴贫、自嘲、表面怂、骨子里有股较真；幽默是他对抗孤独和恐惧的壳 |
| 标志笑点 | 对苏晚的喜好如数家珍却被当怪人；一本正经地给死局写"攻略笔记" |
| 成长弧线 | **把爱与命都当游戏的看客 → 在一条不能读档的时间线里，第一次认真地活、认真地爱。** 他最终明白：她的记忆他保管，但爱不该是一个人的存档——真正的爱，是哪怕注定被忘记，也愿意为她走向没有退路的前方。 |

## 2. 女主：苏晚
| 维度 | 设定 |
|------|------|
| 年龄/身份 | 28 岁，灾变前医学院研究生（感染病方向），灾后独自携带药品求生的游医 |
| 性格 | 冷静、独立、戒备心强、说话直接；不相信奇迹，只相信证据 |
| 独立欲望（非花瓶） | 去北塬——一是为查清灰潮、研究感染治疗，二是她笔记本里夹着一张自己毫无印象的"塬上"童年照片，她要弄清楚自己是谁 |
| 能力 | 医术、药剂替代、对灰潮感染**耐受度远超常人**（身世悬念） |
| 身世埋点 | 幼年可能在北塬净地生活过，与"回档缝隙"相关；为结尾的"似曾相识"提供依据 |
| 情感线（对她永远是第一次） | 她的戒备、试探、心动、托付，每一次都新鲜真实。她不知道自己为什么会对这个"知道得太多"的男人莫名安心，也会警惕他眼神里那份"你本该认识我"的熟稔 |
| 关键细节（他记得，她不知） | 怕苦却会为一颗薄荷糖眼睛发亮；换药时咬嘴唇；守夜时睡着会皱眉 |
| 主动性 | 她不是被保护物——第二章用医术反救重伤的他；第三章在死局中做出自己的选择，而非等他来救 |
| 弧光（短篇侧写） | 从"独自求生、拒绝依附"到"愿意把后背交给一个人"；结尾在失去记忆的状态下，凭无法解释的直觉重新走向他 |

经典错位台词：
- 她："我们以前是不是认识？" 他："……你每次都这么问。"
- 她（警惕）："你怎么知道我喜欢薄荷糖？" 他："猜的。"

## 3. 重要配角
### 老魏（魏长河）——车队主心骨
- 46 岁，灾变前长途货车司机，丧女，沉稳护短，信"车到山前必有路，但你得先把车打着"。
- 江舟与苏晚结伴后护送汇合的车队首领；他把"责任"二字活给江舟看。第三章把方向盘和全车人的命交给江舟。

### 小满（周满）——毒舌孤儿
- 12 岁，老魏养女，机灵嘴毒、负责放哨。
- 第一个察觉异常："江舟哥看苏晚姐的眼神，像在看一个已经认识很久、可苏晚姐根本不认识他的人。" 是情感线旁观点破者，也负责喜剧调剂。

## 4. 主要反派：赵九（人称"灰九"）
- 40 岁，灰狗帮头目。灾变前收费站保安队长，灾变当天开门放邻居逃生，反被邻居为抢物资捅成重伤、丢下等死。从此只信：**末日里先动手的人才配活到明天。**
- 不疯不嗜杀、甚至讲规矩（但规矩由他的刀解释），卡口布明暗三层、有诱饵退路，是值得江舟读档几十次去攻略的对手。
- **与江舟的镜像**：两人都靠"信息差"决生死。第二章对峙时他看穿江舟："别人怕死，我也怕死，只有你——你不是不怕死，你是压根没觉得这条命是真的。你看她的眼神，也不像在看活人。"
- 这句话扎进江舟心里，推动第三章转变。打手**龅牙强**负责具体暴力场面，是关卡小怪式的喜剧凶横。

## 5. 人物关系网与变化
```
        老魏（责任/父辈）
       ╱
江舟 —— 小满（旁观点破者）
  │
  ├──── 苏晚（女主：救→结伴→依赖→爱；单向记忆）
  │
  └──── 灰九（镜像/精神对手）── 龅牙强（爪牙）
```
- **江舟 × 苏晚（主线）**：犬口救下 → 互相利用搭伙 → 无数次寒夜里把后背交给对方 → 相爱；但每轮回档她都陌生。第二章她重新信赖他时他心碎于"只有我记得"；第三章他学会不依赖存档去爱，她则凭直觉重新选择他。
- **江舟 × 老魏**：从被戒备的陌生人到以命相托。
- **江舟 × 小满**：互怼；她童言无忌地戳破错位。
- **江舟 × 灰九**：智斗与精神镜像，灰九的话成为他转变的外力。

## 6. 人物写作注意
- 幽默由江舟独白、小满对话、江舟与苏晚的"错位"承担；老魏负责压住基调，避免轻浮。
- **苏晚必须始终有主体性**：她的爱不是被攻略的结果，而是她自己的判断；她不依附江舟。
- 单向记忆的痛主要靠细节呈现，不靠哭诉；点到即止，留白处才扎心。
- 灰九逻辑越成立，江舟要反驳、要守护的东西才越重。
