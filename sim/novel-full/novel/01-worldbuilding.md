# 世界观设定 ·《废土读档指南》

## 1. 时代与地理环境
- **灾变**：三年前发生"大沉寂"。一种失控的纳米级生物胶体——人称"**灰潮**"——从沿海的生物实验设施泄漏，随大气环流扩散，90 天内全球电子文明瘫痪。
- **为什么叫"沉寂"**：灰潮以复杂电路与精炼金属为能量源，通电即噬、遇精密金属即蚀。电网、通讯、芯片、车辆 ECU 全部永久失效，世界在一夜之间失声。文明被强行打回"前电子时代"：机械柴油车（拆掉电控、改直喷）、老式步枪、纸质地图、短波电台（仅在低灰区偶有杂音）重新成为主流。
- **故事舞台**：架空内陆江城——**临江市**废墟。长江支流穿城，大桥坍塌、高楼成了鸟巢一样的空壳。江舟的活动范围在城南旧居民区到城西高架之间。
- **灰区划分**（可被生存者经验化判断）：
  - **重灰区**：城市下风下水方向、地下空间、浓雾常驻处。能见度低，变异体多，金属锈蚀快。
  - **轻灰区**：开阔地、上风上坡处、雨后。相对安全，是扎营首选。
  - **净地**：极少数灰潮无法存活的环境——高浓度盐碱地、陈年石灰窑、特定地下泉眼周围。北塬聚居地传说就建在一片天然净地上。
- **检测手段**：苔藓试纸（颜色变灰即浓度超标）、看铁锈速度、观察鸟雀是否绕行。简单、土法、可靠。

## 2. 主要势力与组织
| 势力 | 性质 | 与主线关系 |
|------|------|-----------|
| **老魏车队** | 平民互助小队，四辆改装柴油卡车+十几口人，做"城南—锈市"的短途运输 | 江舟卷入并保护的对象，情感锚点 |
| **灰狗帮** | 盘踞城西收费站与高架的掠夺者团伙，设卡、绑票、黑吃黑，约三四十人 | 第一、二章主要人形反派，像"关卡 BOSS" |
| **锈市** | 高架桥底的中立交易集市，以物易物，有自己的武装中立规矩 | 信息与物资枢纽 |
| **北塬聚居地** | 北方三百里外传说中的大型净地聚落，有秩序、有农业 | 车队的远方目标，悬念灯塔 |
| **独行者/拾荒者** | 江舟前期的身份群体 | 视角窗口 |

势力关系：车队要活下去就得过路，过路就得给灰狗帮上贡或被吃；锈市两边做生意、不站队；北塬是所有人的希望但路途九死一生。

## 3. 核心规则体系
### 3.1 灰潮与变异体（世界规则）
- 灰潮本身不直接"吃人"，它改造生命：长期暴露者先咳灰痰、金属饰物发黑，继而器官纤维化死亡；极少数生物（含人）挺过感染则发生**变异**。
- **变异体示例**：
  - **裂脊犬**：流浪犬变异，体型增大、背脊裂开感光，群居，靠震动与体温定位，**怕火、怕强光、怕酒精雾气**。
  - **灰皮猴**：行动敏捷、会模仿人声诱捕，智力接近孩童。
- 规律：变异体**白昼蛰伏、晨昏活跃、雾天狂暴**；从不进入净地；对新鲜电子设备有本能趋附（会循"活着的机器"聚集——这也是没人敢尝试修电器的原因之一）。
- 生存铁则：湿布蒙面、雾不出门、点火守夜、不上下风下水的厕所。

### 3.2 无限重生（主角独有超凡规则——自洽、可推演）
1. **触发**：江舟确认死亡后，意识与肉体一并回溯到当前"**锚点**"：伤势痊愈、身上物资回档到锚点时刻，**记忆完整保留**，包括痛感与死亡体验。
2. **锚点初始形态**：他觉醒那天的清晨，城南出租屋藏身点。
3. **锚点推移（核心代价）**：锚点不是固定存档，当江舟在一条时间线里做出"上一条时间线的他绝不会做的选择"——即真正的改变与成长——锚点会在下次死亡时**向前更新**到最近一处他曾安心度过六小时以上的地方。他无法永远赖在过去。
4. **边界**：
   - 世界随他一起回档：他救的人、改变的事、花掉的人情全部重置，**所有人的意识与记忆也一并回到锚点时刻，只有他记得**。对别人而言他只是个陌生人；对他而言，全世界都是"第二次见面"。
   - 死亡过程 100% 真实，心理疲劳与恐惧会累积；他不是不怕死，是死得太熟。
   - 他若不死，时间对所有人一样无情流逝，没有暂停键。
   - 无法把能力"告诉系统"——没有系统、没有面板、没有任务奖励，只有一次次睁眼。
5. **裂缝（悬念埋点）**：江舟感染灰潮后没死透反而觉醒；灰潮的纳米胶体能"刻录"金属与环境信息，而他的大脑似乎成了唯一能刻录"时间"的介质。北塬的净地与灰潮的秘密，是续作与第三章结尾遥指的远方。

### 3.3 记忆的单向性（情感线机制基石）
- 回档不是"穿越回旧世界"，而是**整个世界连同所有人的意识被还原**。因此苏晚每一次都真真切切地第一次认识他——她的戒备、好奇、心动，对她本人都是新鲜且唯一的，从不作假。
- 江舟无法用"我们以前认识"解释自己的熟稔（说出口也只会被当疯子或骗子），只能一次次重新靠近。
- **规则缝隙（仅埋点、不点破）**：极少数在净地长大、或对灰潮天然低亲和的人，其"身体直觉"似乎不完全受回档约束——肌肉记忆、气味偏好、莫名的安心感偶尔会残留。这不是记忆恢复，更像一种无法解释的熟悉，为第三章结尾的"我好像认识你很久了"提供机制可能。

## 4. 社会结构与日常风貌
- **硬通货排序**：干净水 > 抗生素/盐 > 柴油 > 弹药 > 罐头。钱是废纸，"水票"在锈市流通。
- **经济**：拾荒、改装、护卫、运输、以命换物。手艺人（修机械的、酿私酒的、会看病的）地位高。
- **日常**：日出而作、日落封门；车队靠车载铁皮炉做饭；晚间讲"旧世界"的故事是主要娱乐——WiFi、外卖、手机是孩子们眼里的神话。
- **笑点土壤**：别人对"死"字讳莫如深、谈变异体色变；江舟却面不改色地拿"我上次死在这"当口头禅，在旁人眼里是个深不可测的疯子狠人——**信息差喜剧**由此而来。

## 5. 禁忌、代价与世界的裂缝
- **禁忌**：在室内给电子设备通电（等于给变异体发坐标）；雾天开门；收留咳灰痰的人；欠锈市的账。
- **代价**：每一次重生都只有他记得——被他救过又回档消失的人，不会道谢；他杀过的人，醒来后依然"无辜"地活着。道德重量全部由他独吞。
- **裂缝**：
  1. 锚点为何会随"成长"前移？是灰潮在筛选什么，还是他自己的潜意识在推自己往前走？（第三章点到即止）
  2. 北塬净地是否真的存在？灰潮有没有"意志"？
  3. 苏晚为何对灰潮感染的耐受度远超常人？她笔记本里夹着一张童年在"塬上"的照片，自己却全无印象——她与净地、与回档缝隙之间有何渊源？
  4. 第三章的死局设计：一个**靠死亡试错也无法通关**的局——锚点已越过关键抉择点，他第一次必须在没有退路的情况下成为自己"演"了很久的那种人。
